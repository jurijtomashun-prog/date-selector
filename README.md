# Свиданко-селектор

Мобильное приглашение на свидание. Выбор сохраняется только в браузере, а итог экспортируется в календарный файл `.ics` без отправки данных на сервер.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm test
npm run lint
npm run build
```

## GitHub Pages

1. Создайте репозиторий и отправьте проект в ветку `main`.
2. Откройте **Settings → Pages**.
3. В **Build and deployment → Source** выберите **GitHub Actions**.
4. Workflow `.github/workflows/deploy.yml` протестирует, соберёт и опубликует сайт.

Относительный `base` в Vite позволяет публиковать проект под любым именем репозитория.
